# 叙事手册：聊天腔外壳，因果链内核

来自 97 支字幕的统计与 6 支样片的逐段拆解。下面的示例句都是原创，只示范手法；不要搬原频道的句子。

## 文案指标（成片口径）

| 指标 | 目标 | 说明 |
|---|---|---|
| 语速 | 约 6 字/秒（录音约 4.8，剪掉气口后到 6） | align_recording.py 压停顿后自动接近 |
| 设问 / 反问 | 1–2 次/分钟 | 抛出后下一句立刻自己回答 |
| 数字 | 3–4 个/分钟 | 每个关键数字配一个参照物：「比 X 一家还多」「是 Y 的 23 倍」 |
| 英文术语 | ≈1 个/分钟 | 英文原词 + 一句中文大白话，画面出术语卡 |
| 开场到「今天聊…」 | 要么 ≤3 秒直给，要么 40–60 秒钩子 | 不要卡在中间 |

## 三种骨架

### A 危机 / 暴雷型（怎么死的）——银行倒闭、暴雷、骗局
1. 时间线速览 + 量级对比（日期贴纸逐个叠上，倒下的划红线；先证明「这事很大」）
2. 替观众说出质疑：「有人可能觉得…」→ 用数据反驳（stage 柱状图）
3. 交接句进入正文（一句话翻开第一章）
4. 主角怎么起家（客户是谁、凭什么做大，顺手一个小调侃）
5. 宏观推力：钱从哪来（三步因果，每步一个数）
6. 「重点来了」：一个当时看起来很合理的错误决定（先替对方讲清当时为什么这么想）
7. 机制解释：术语卡 + 生活比喻 + 模拟走势图；需要时加「硬核预警，跟不上可以跳过」
8. 为什么没人发现：会计、监管的盲区；接一句和观众钱包有关的话
9. 导火索 + 拟人独白：把公告翻译成市场听到的潜台词（卡通贴纸 + 气泡）
10. 高潮：挤兑/暴跌，大数字滚动，一个字或一个词收尾
11. 支线 + 坦白不确定（「我没查到直接原因，可能是…也可能是巧合」）
12. 「性质变了」：从个案升级成恐慌；第二人称假设「要是你的钱存在…你慌不慌」
13. 善后：只有两条路 + 竞猜停顿（「你猜多少钱？」→ 停半秒 → 答案）
14. 复盘：三个原因排主次，其中一个只算「半个」；落到人性（贪婪、侥幸）
15. 展望：「先说答案」+ 一个类比
16. 结尾回扣开头的私人话题 / 互动提问

### B 收购 / 博弈型（怎么打的）——恶意收购、董事会之争、巨头混战
1. 冷开场：日期 + 金额大数字（写满所有的零）
2. 「最有意思的是 X」：抛出一个核心概念
3. 问题云：本期要回答的 3–4 个问题，随后合并成章节标题
4. 给跳转点：只想听干货的可以跳到 X 分 X 秒
5. 事件经过：每一步配文件证据卡（标黄关键数字）
6. 悖论：「X 不是很厉害吗，怎么还是成了？」
7. 虚构小例子讲规则（街角奶茶店、小区业委会这种生活化场景）
8. 进攻方的几招：中英文命名，逐个讲，画面上术语卡横排成「武器清单」
9. 「精彩的逻辑来了，跟住」：思想实验，带具体数字算一遍
10. 防守方的武器：机制、起源、法律依据、经典案例
11. 回到本案：最后为什么松口/成交
12. 武器清单汇总 + 一条原则收尾

### C 悖论型（为什么反常）——「被卡脖子还能第二」「越加息越涨」
1. 冷开场：反常事实 + 冲击数字
2. 摆出悖论（两件看似矛盾的事并列）+ 问题云
3. 章节一：先把「卡了什么」讲清楚（时间线 + 来回拉锯，偶尔一句吐槽：「这还是管制吗？更像收过路费」）
4. 纠偏：「准确地说，不是 X，是 Y」
5. 章节二：「第二」怎么算的（权威榜单 + 差距变化，主动提到对方的保留意见）
6. 章节三：靠什么追——编号的几条，每条一个画面手法（术语卡 / 下载份额柱图 / 空镜比喻 / 梗）
7. 章节四：不好听的数据（算力份额、投资差距），平衡
8. 一句话总结（毛笔大字）→ 复盘两面 → 先说答案的展望 → 结尾互动

## 活人感手法（每期至少用 3 个）

| 手法 | 原创示例 | 画面 |
|---|---|---|
| 开场个人状态 | 「这周嗓子有点哑，大家将就听」 | 主播全屏，可插自拍 |
| 观众点题 | 「后台好多人问同一件事」 | 私信卡左右弹出 |
| 替观众说质疑 | 「你可能觉得，倒一家很正常嘛？还真不正常」 | 盖章大字 |
| 拟人独白 | 银行：「我亏钱了…钱不够了…谁能借我点？」 | 卡通贴纸 + 气泡逐句 |
| 生活比喻 | 「利率和债价像跷跷板」「穷人家的孩子更会过日子」 | 生成的比喻空镜 |
| 叠词节奏 | 「买买买」「亏亏亏」 | 大字连跳 |
| 一词收尾 | 「卒」「过路费？」 | stamp-red |
| 坦白没查到 | 「后来交付了多少？我查了一圈没找到靠谱数据」 | 大字 |
| 竞猜停顿 | 「你猜多少钱？——一英镑」 | stage quiz |
| 先说答案 | 「先说答案：短期稳，长期看两件事」 | list 两条 |
| 真实经历 | 只用主播本人真实经历；剧本里留空位让用户填，绝不编 | — |
| 结尾回扣 | 回到开头的私人话题 / 「评论区告诉我」 | 全屏 |

## 语言习惯（节拍词）

按每 10 分钟出现次数：其实 11.5、咱/咱们 10.1、你看 6.6、比如说 3.7、你说 3.1、对吧 2.2、你想 1.9、是不是 1.5。

- 「你看」= 要切图了：说出口的同一帧切到图表/素材。
- 「其实」= 纠正直觉，后面跟反常识信息。
- 「咱」= 把观众拉到同一边（北方口语的亲近感）。
- 「对吧 / 是不是」= 确认跟上，相当于一个停顿。
- 「你说 / 你想」= 开一个第二人称假设场景。
- 「当然 / 不过」= 给判断留余地，不武断。

学的是功能，不抄口头禅本身。给主播设计自己的标志词（示例集用「掰开揉碎」代替「一口气」）和固定结尾。

## 写拍表时的节奏规则
- 主播全屏一次 5–8 秒（新近风格 2–3 秒），观点和情绪句用全屏。
- 一提到具体事物（公司、人、文件、数字）就切素材或上舞台。
- 图表一张停 8–10 秒，随口播逐步揭示（bars 每根一个 cue）。
- 全屏拍之间用 punch 1.08–1.15 推近盖跳切。
- 每 2–3 分钟一个情绪出口（梗 / 贴纸独白 / 吐槽大字）。
