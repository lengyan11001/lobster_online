# 从一张照片做一个新数字人

1. **照片**：一张正脸、光线均匀、头发不挡脸的人物照（数字人照片或自己的生活照都行）。从视频里取帧时挑嘴闭着的一帧。只用本人或明确同意的人的照片。
2. **上传**：upload_files → 拿到 `material:<id>`。
3. **四视图**：gpt-image-2.5-sunburst 2k 16:9（约 23 credits），提示词要点：同一个人、同一套衣服发型，四格并排——正面 / 左侧 / 右侧 / 背面，浅灰无缝背景，不出现任何文字。
4. **多模型对比**：同一句 8 秒台词各拍一版
   - Grok Video 1.5 720p（约 136 credits）：参考图模式，表情手势更自然，自带中文配音
   - Wan 3.0 720p（约 96 credits）：首帧模式，更便宜
   两版并排看：脸像不像、口型对不对、动作自不自然、声音喜不喜欢。
5. **选定**：把选中模型和 material id 写进 persona.json（reference_material、look、voice.desc）。
6. **先拍一段**：用 build_tasks.py 拍第 1 段确认音色，满意了再批量。
