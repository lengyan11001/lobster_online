# 数字人3.0 模板引擎改造计划

## 产品原则

用户只看到三步：

1. 上传形象、写口播稿
2. 选一个模板
3. 生成成片

不暴露 48 个包装组件、模型 ID、渲染参数、时间轴术语。  
高级参数统一收进「高级设置」，默认收起。

## 页面交互

- 左侧：形象、口播稿、高级设置、主按钮「生成第 1 段」
- 右侧：预览、模板选择、成片下载、项目记录
- 首屏只展示 6–8 个推荐模板，不一次性铺满
- 模板库支持分类、搜索、最近使用、收藏、换一批
- 卡片只展示：封面/样片、名称、一句话说明、适用场景
- 生成中只显示：当前阶段、百分比、预计剩余
- 项目记录每条只显示：封面/名称、状态、时间、预览/打开/删除

## 技术分层

### 1. TemplateSpec

模板协议负责描述：

- 槽位：人物视频、产品图、截图、BGM
- 场景：开场、正文、转折、结尾
- 图层：人物、字幕、标题、卡片、角标、CTA
- 时间轴：进入/退出、关键帧、转场
- 样式：字体、颜色、描边、投影、动画曲线
- 规则：安全区、每场景最大字数、节奏间隔

### 2. 渲染器

- 标准模板：ffmpeg + HTML/CSS 叠层
- 高级模板：可插拔 Revideo/Remotion
- 预览：480p / 12fps
- 成片：720p 或 1080p / 30fps
- 只渲染叠层，不重复编码底片；底片原音轨直接复用

### 3. 底片抽象

底片来源以后接 Grok/Hifly/LatentSync/MuseTalk/用户上传。  
模板引擎只接收：

```text
video_path, audio_path, duration, face_bbox, alpha_video?
```

## 阶段

### P0 当前（引擎验证）

- TemplateSpec v0
- 先用 3 个样张验证引擎：爆点口播、质感访谈、带货强钩子
- 3 个不是最终模板数量，只是 P0 的验证样本
- 单底片 + 高级叠层
- 模板卡片选择、成片下载
- 抽帧质检

### P1（模板库）

- 模板扩到 30–50 个
- 分类：口播观点、带货转化、知识教程、访谈纪实、新闻资讯、测评对比、情绪剧情、矩阵批量
- 每个基础版式支持 3–5 个样式变体（配色、节奏、字幕位置）
- 首屏推荐 6–8 个，全部模板进二级库
- 分类、搜索、最近使用、收藏、换一批
- 模板封面/样片、模板版本
- 多场景、B-roll、画中画、转场
- 批量文案/形象/声音

### P2（模板市场）

- 模板扩到 100+
- 模板商店、付费模板、作者体系
- 可编辑草稿导出（剪映/CapCut）
- AI 自动选模板、自动卡点、按文案推荐模板

## 模板数量策略

3 个不是产品上限，是 P0 的验证范围。

正确的产品形态不是“只给 3 个”，也不是“一次给 100 个让用户自己翻”，而是：

- 首屏 6–8 个推荐
- 按内容类型分 8 类
- 每类 4–8 个精选模板
- 每个模板 3–5 个样式变体
- 支持搜索、标签、最近使用、收藏、换一批
- 低质量模板不上架，模板必须有封面、样片、适用场景、时长/比例

目标数量：

- P0：3 个（验证引擎）
- P1：30–50 个（可用模板库）
- P2：100+（模板市场）

## 验收

- 用户不打开高级设置也能完成一条成片
- 模板切换后，预览和成片必须变化
- 同一底片切换模板不重新生成底片、不重复扣底片算力
- 渲染失败能保留底片和任务记录，可重试
