# 视频号获客

参照「抖音获客」做的视频号版本，入口在 **AI获客 → 视频号获客**。

## 结论：可以做，但不能 1:1 照搬抖音

视频号没有独立网页版，公开数据入口和创作者后台是两套东西：

| 能力 | 是否可做 | 实现方式 | 实测 |
|---|---|---|---|
| 关键词搜视频 | ✅ | TikHub `wechat_search/v2/fetch_search_videos` | 「装修」返回 10-20 条 |
| 视频详情 / 作者 | ✅ | TikHub `wechat_channels/v2/fetch_video_detail` | exportId + feedNonceId 换到 objectId、username、点赞/评论数 |
| 一级评论采集 | ✅ | TikHub `wechat_channels/v2/fetch_video_comments` | 单视频实测 26 条 |
| 同行账号作品 | ✅ | TikHub `wechat_channels/v2/fetch_user_videos` | 按 username 拉主页作品 |
| 我的评论区 | ✅ | 视频号助手 `/platform/comment` | 页面存在，需扫码登录 |
| 私信回复 | ✅ | 视频号助手 `/platform/private_msg` | 页面存在，只能回复已有会话 |
| 主动冷私信 | ❌ | 无公开接口 | 抖音式主动私信不能照搬 |
| 关注 / 点赞 / 评论别人 | ❌ | 视频号助手只能管自己作品 | 需微信客户端 UI 自动化 |
| 群成员提取 | ❌ | 无公开接口 | 需微信客户端 UI 自动化 |
| 账号养号 | ❌ | 无公开接口 | 需微信客户端 UI 自动化 |

视频号助手本身可访问：`https://channels.weixin.qq.com/platform` 返回 200，标题「视频号助手」，前端路由里存在 `/platform/comment`、`/platform/private_msg`。

## 页面与流程

入口页：`/channels`（SPA，左侧 17 个模块，和抖音获客保持同一套布局）。

推荐流程：

1. 配置中心确认 TikHub 已配置；扫码登录视频号助手。
2. 搜索采集：输入关键词 → 选中视频 → 采集评论。
3. 全部客户 / 精准客户：按意向词和问句打分，导出 CSV 或加入精准。
4. 私信互动：先采集视频号助手私信会话；只能回复已有会话。
5. 我的评论区：采集自己作品评论，做二次跟进。

## 主要接口

```
GET  /api/channels/capabilities          能力边界
GET  /api/channels/config                配置（Key 打码）
POST /api/channels/config                保存配置
POST /api/channels/search/collect        关键词搜索
POST /api/channels/tasks/from-search     选中视频建评论任务
POST /api/channels/tasks/{id}/run        采集评论
GET  /api/channels/customer-pools        全部/精准客户
GET  /api/channels/monitor/targets       同行监控
POST /api/channels/monitor/targets/{id}/refresh
GET  /api/channels/inbox/status          私信会话
POST /api/channels/inbox/collect         采集私信会话
POST /api/channels/inbox/send            发送私信
POST /api/channels/self-comment-monitor/run-once  我的评论区
GET  /api/channels/scheduler/plans       排期计划
```

## 验证

```powershell
python -m pytest backend/tests/test_channels_api.py -q
```

结果：`4 passed`。覆盖能力边界、搜索→详情→评论→精准客户链路、Key 打码、抖音式能力返回不支持。
