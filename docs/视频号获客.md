# 视频号获客

入口：**AI营销创作 → 视频号获客**。

实现方式：本地微信 PC 客户端 UI 自动化（UIA），不接 TikHub，不需要用户配置任何 Key。

## 权限

- 管理后台权限包：`channels_leads` / `channels_leads_access`
- 名称：视频号获客入口
- 管理后台「入口权限」里给用户/代理商授权后，AI营销创作下显示入口。
- 客户端 gate：`channels_leads_access`。

## 已走通

| 能力 | 实现 |
|---|---|
| 视频搜索 | 微信左侧「视频号」→ 搜索框 → 结果卡片 |
| 视频评论 | 视频详情 → 评论按钮 → 评论面板 → 滚动加载 |
| 账号搜索 | 搜索结果页「账号」tab → 账号卡片 |
| 账号联系方式 | 从账号简介提取手机号 / 微信号 / QQ |
| 客户池 | 评论客户 + 账号简介客户，意向词打分 |
| CSV 导出 | 客户 / 账号 |
| 窗口状态 | 微信主窗口、视频号窗口、当前页面 |

## 明确不做

- 主动冷私信：本地视频号 UI 没有私信入口，作者主页只有「关注」，个人中心没有消息中心。
- 关注 / 点赞 / 评论别人：本轮只做只读采集，不执行写操作。
- 我的评论区：当前账号 0 个作品，未实测；有作品后可按视频评论同样方式采集。
