# 视频号获客

入口：**AI营销创作 → 视频号获客**。

实现方式：本地微信 PC 客户端 UI 自动化（UIA），不接 TikHub，不需要用户配置任何 Key。

## 权限

- 管理后台权限包：`channels_leads` / `channels_leads_access`
- 名称：视频号获客入口
- 管理后台「入口权限」里给用户/代理商授权后，AI营销创作下显示入口。
- 客户端 gate：`channels_leads_access`。

## 已走通

| 能力 | 实现 |
|---|---|
| 视频搜索 | 微信左侧「视频号」→ 搜索框 → 结果卡片 |
| 视频评论 | 视频详情 → 评论按钮 → 评论面板 → 滚动加载 |
| 账号搜索 | 搜索结果页「账号」tab → 账号卡片 |
| 账号联系方式 | 从账号简介提取手机号 / 微信号 / QQ |
| 客户池 | 评论客户 + 账号简介客户，意向词打分 |
| CSV 导出 | 客户 / 账号 |
| 窗口状态 | 微信主窗口、视频号窗口、当前页面 |

## 明确不做

- 主动冷私信：本地视频号 UI 没有私信入口，作者主页只有「关注」，个人中心没有消息中心。
- 关注 / 点赞 / 评论别人：本轮只做只读采集，不执行写操作。
- 我的评论区：当前账号 0 个作品，未实测；有作品后可按视频评论同样方式采集。

## AI 评判与深搜

- 深搜：一个关键词自动拆成多个查询（种子词 + 怎么选/推荐/价格/加盟/本地/避坑/案例/公司），去重后合并。
- 视频筛选：最低点赞、平均点赞倍数、历史重复排除；直播卡片自动跳过。
- 评论分层：默认先看 80 条，AI 命中 >=3 人或命中率 >=5% 时自动加深到 200/300 条。
- AI 评判：返回 score、intent_level、reason；任务同时保存 all_comments 和 high_intent_users。
- 总结：任务详情显示评论数、精准数、命中率、地区分布和前 8 个精准客户。
- 窗口：采完自动关闭评论面板和多余视频号窗口，只保留一个。


## 更深一层：相关搜索 / 同行作品 / 人工反馈

- 相关搜索扩词：搜索页右侧「相关搜索」自动提取，加入深搜查询矩阵。
- 同行作品：深搜可选「含同行」，先搜账号，再按账号名搜作品，合并进视频候选。
- 人工反馈：任务详情每条评论可点「精准 / 误判」，写入反馈库；下次 AI 评判会把最近的正例/反例加入提示词。
- 所有来源统一去重、统一 AI 评判、统一客户池。
