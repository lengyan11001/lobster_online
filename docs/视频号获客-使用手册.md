# 视频号获客 · 使用手册

## 0. 前置条件

1. 本机微信 PC 端已登录。
2. 微信左侧能打开「视频号」。
3. 客户端已更新到包含「视频号获客」的版本。
4. 管理后台已给当前用户/代理商勾选 **视频号获客入口**（权限 key：`channels_leads_access`）。
5. 配置中心显示 **AI 可用**。

入口：**AI获客 → 视频号获客**。

## 1. 第一次配置

打开「配置中心」：

| 配置 | 建议 |
|---|---|
| 默认视频数 | 50-100 |
| 初始评论数 | 80 |
| 深度上限 | 200（重点视频可 300） |
| 加深触发精准数 | 3 |
| 视频最低点赞 | 500 |
| 平均点赞倍数 | 1.5 |
| 排除历史重复 | 是 |
| 筛选策略 | 正向筛选 |
| 精准客户筛选提示词 | 写你的业务口径 |
| 模型 | 留空用默认 |

提示词示例（装修）：

```
有真实装修需求、询问价格、询问能否施工、询问怎么联系、
描述自己的房型/位置/改造需求的人。
排除纯夸赞、纯围观、玩笑、作者自评、同行广告、无关闲聊。
```

## 2. 深搜视频

进入「搜索采集」：

1. 输入种子关键词，例如 `装修`。
2. 默认视频数填 50-100。
3. 保持「深搜」勾选。
4. 需要同行作品时保持「含同行」勾选。
5. 点「搜索采集」。

系统会：

- 种子词 + 后缀词（怎么选/推荐/价格/加盟/本地/避坑/案例/公司）
- 搜索结果右侧「相关搜索」自动扩词
- 可选：先搜同行账号，再按账号名搜作品
- 合并后按标题+作者+时长+发布时间去重
- 跳过直播卡片
- 按最低点赞、平均点赞倍数、历史重复筛选

结果表里看：

- 「命中 / 未命中」：是否达到视频筛选条件
- 「历史重复」：之前采过
- 默认只勾选命中的视频

## 3. 采集评论

1. 在搜索结果里勾选目标视频。
2. 点「采集选中视频评论」。
3. 系统对每个视频：
   - 先采 80 条评论
   - AI 评判
   - 如果精准 ≥3 人或命中率 ≥5%，自动加深到 200/300 条
   - 连续 2 轮无新评论就停
   - 采完关闭评论面板和多余窗口

一个视频通常 20-60 秒；重点视频加深会更久。

## 4. 看任务总结

进入「视频评论」，点任务的「查看」。

顶部会显示：

```
评论 6 条 · 精准 3 人 · 命中率 50.0% · 地区 广东 6
```

下面两个视图：

- **全部评论**：采集到的所有评论
- **精准客户**：AI 判定为精准的客户

每条精准客户显示：

- 昵称
- 评论正文
- 地区 / 时间
- 点赞 / 回复数
- AI score
- AI 判定理由

## 5. 人工纠偏

每条评论后面有：

- **精准**：把这条评论加入精准客户
- **误判**：从精准客户里移除

反馈会写入反馈库；下一次 AI 评判会把最近的正例/反例加入提示词。

同一条评论再次反馈会覆盖旧反馈，不会产生矛盾样本。

## 6. 客户池与导出

进入「全部客户 / 精准客户」：

- 查看评论客户 + 账号简介客户
- 看到联系方式（手机/微信/QQ）
- 导出 CSV
- 精准客户只来自 AI 判定 + 人工标记，不再用正则阈值

## 7. 账号采集

进入「账号采集」或搜索页点「搜账号」：

- 抓账号名、认证、简介、视频数、更新时间
- 从简介提取手机号/微信号/QQ
- 有联系方式的账号自动进精准客户

## 8. 运行时长参考

| 操作 | 预估 |
|---|---|
| 单次关键词搜索 | 10-20 秒 |
| 深搜 6 个查询 | 1-2 分钟 |
| 深搜 + 同行作品 | 2-4 分钟 |
| 单视频 80 条评论 | 20-40 秒 |
| 单视频加深到 200 条 | 40-90 秒 |
| 30 个视频第一轮 | 15-25 分钟 |

## 9. 常见问题

**Q：搜索框里关键词重复叠加？**  
已修：每次搜索先全选再粘贴，并用 ValuePattern 兜底。

**Q：打开视频后提示找不到视频号窗口？**  
已修：打开视频后窗口标题会变成作者/视频标题，现在按微信窗口+文档节点识别。

**Q：视频详情找不到评论按钮？**  
通常是点到了直播卡片。现在直播卡片自动跳过；如果仍遇到，回到搜索结果重试。

**Q：精准客户为空？**  
检查配置中心 AI 是否可用；看任务详情是否有 AI 错误；没有评论时无法评判。

**Q：窗口越来越多？**  
采完自动关闭评论面板和多余视频号窗口；正常只保留一个视频号窗口。
